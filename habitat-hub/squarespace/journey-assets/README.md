# Journey / sprite assets for Squarespace

Extracted from the site's own artwork, backgrounds removed (true alpha
transparency, not blend modes) so they sit on any colour.

## Off-site journey section (Developers page)
- `sp-building.png` — "Your development" end of the diagram
- `sp-tree.png` — "A Biofarm Habitat Bank" end
- `sp-dandelion.png` — the drifting seeds along the path (place 2–3,
  rotated/scaled differently, opacity ~.6–.9)
- `journey-path.png` — the dotted survey path as a 2400x480 transparent
  PNG (~7KB). USE THIS for Squarespace image blocks - the uploader does
  not accept SVG. Green #71977A.
- `journey-path.svg` — same path as vector. Squarespace images reject it;
  use only pasted INLINE inside a Code Block (it is 12 lines).

## Rest of the sprite set (heroes, marginalia)
- `sp-fern.png`, `sp-bee.png`, `sp-orchid.png`
- `england-map.png` — the line-drawn coastline (white-normalised)

PNGs upload to Squarespace as-is (image blocks or CSS backgrounds).
The SVG can be uploaded via Design → Custom CSS assets, or pasted inline
inside a Code Block.
